Backup & export

Save a copy of every idea in all four drawers whenever you want.

PDF A readable copy of everything: every skit, story, novel and video with all its notes.
Backup file A .json file you can load back into Bit Drawer later to restore everything.
Restore Load a backup file. Ideas in it are added back; nothing you have now is removed.

Sync with GitHub

Your ideas are saved to data.json in a private GitHub repo, so every device sees the same drawer. Do this once per device.
  1. Make a private repo (for example bit-data) and upload the data.json file into it.
  2. Create a fine-grained token: pick only that repo, and set Contents to Read and write.
  3. Paste it below. It stays in this browser only.
